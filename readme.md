# Personal Expense Tracker (Python Mini Project)

##  Objective
A command-line based Python app to track personal expenses using file handling and summaries.

##  Features
- Add expenses with amount, category, and date
- View total expenses and category-wise summary
- Data saved in `expenses.json` for reuse between sessions
